# Supercell_-Tracker
Crée un site appelé SuperTracker, inspiré de Fortnite Tracker, pour suivre les profils Supercell. Commence avec Brawl Stars et Clash Royale. Recherche par Player Tag, affiche les statistiques disponibles via les API officielles, avec une interface moderne sombre et adaptée à l’iPhone. Prévois l’ajout d’autres jeux.
